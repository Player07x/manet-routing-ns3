# data/

Resultados da simulação entram aqui:

- `raw/` — CSV bruto, exatamente como `./ns3 run scratch/manet-routing` gera (`resultados-aodv-olsr-dsdv.csv`).
- `processed/` — dados agregados (médias, desvio padrão) usados para gerar os gráficos em `../figures/`.

Pendente até a bateria completa (120 execuções) ser rodada — ver o `README.md` na raiz do repositório.
